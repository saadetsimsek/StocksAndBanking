# StocksAndBanking

Stock watchlist application built on the Finnhub API.

## Overview

- Swift and UIKit, written in code without storyboards
- MVVM, with Combine driving the search debounce and the data flow between screens
- Price history drawn in a custom chart view built on Charts
- FloatingPanel for the news panel, SDWebImage for remote images
- The watchlist is persisted locally through a persistence manager
